# 2607.18360v1 — HALLMARK: Diagnosing Three Failure Modes in LLM Citation Verifiers

**Relevance:** skip
This is a benchmark paper for LLM-based citation-metadata hallucination verifiers (frontier models only, no small-model or quantization results); it has no bearing on post-training a 1.2B on-device tool-calling model.

## TL;DR

Hallmark is a 2,526-entry benchmark for evaluating tools that detect fabricated/hallucinated BibTeX citations, testing frontier LLMs (GPT-5.x, Claude, Gemini, DeepSeek, Qwen, Mistral, Llama 4) zero-shot and agentically. Its central finding — false-positive rate, not recall, decides deployability, and naive "any-source-no-match" agentic tool use inflates false positives — is about citation verification, not about tool-calling/structured-output post-training for a small model.

## Baselines & datasets used

- All evaluated systems are frontier-scale or API tools: "GPT-5.1 [OpenAI, 2025]... DeepSeek-R1, DeepSeek-V3.2... Qwen3-235B and Qwen3-VL-235B-Instruct... Mistral Large... Gemini 2.5 Flash and Pro... Llama 4 Maverick, Claude Sonnet 4.6, and Claude Opus 4.7" (§5.1) — none at or below 8B parameters, so no number here is usable as a small-model reference point per the brief's guidance.

## Pitfalls / negative results

- Naive agentic tool use degrades precision, an observation possibly worth remembering as a general caution for any agentic/tool-augmented evaluation harness this project might build for malformed-tool-return probing: "Agentic lookups buy recall but inflate false positives... swapping Sonnet 4.6 for GPT-5.1 reproduces the profile within ≤3.5 pp on every metric" (§5.2) — the inflation came from the harness's "any-no-match" flagging policy, not the base model, and switching to consensus-based flagging "cuts FPR from 0.73 to 0.05" (§5.2). This is a generic lesson about harness design amplifying false-positive rates, not something this project can directly borrow (different task, different failure signal).
- At the fixed evaluation token budget, "the structured JSON-output contract holds across the entire cohort" for most models, but "Three families of post-snapshot thinking-tier models break this contract... emitting chain-of-thought scratchpad before the verdict and exhausting the budget mid-reasoning" (§7/Appendix) — a mild, generic reminder that structured-output reliability can fail under budget/reasoning interactions, but reported only for large frontier reasoning models, not for anything comparable to LFM2.5-1.2B.

## Metric / eval choices

- Uses prevalence-invariant metrics (detection rate / false-positive rate) plus tier-weighted F1 and MCC and ECE for calibration — a reasonable general evaluation-design pattern (dual scoring against a fixed positive/negative target, tier-weighting by difficulty) but built for a binary citation-verification task, not transferable to this project's tool-call schema-validity or malformed-tool-return flag-rate/false-flag-rate targets beyond the general idea of "score a pair, not one number alone" that this project's brief already specifies independently.
