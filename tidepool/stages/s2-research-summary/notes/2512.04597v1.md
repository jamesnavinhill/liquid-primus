# 2512.04597v1 — When Robots Should Say "I Don't Know": Benchmarking Abstention in Embodied Question Answering

**Relevance:** medium
Different domain (vision-language embodied QA / robotics, not text tool-calling), but its core finding — SFT-taught "abstain vs. answer" behavior often reflects surface lexical pattern-matching rather than grounded judgment — is a directly transferable pitfall for this project's "flag malformed tool return" objective, and its prompting results bear on whether the 0.80/0.10 flag-rate targets are realistic.

## TL;DR

The paper builds AbstainEQA, a benchmark testing whether embodied VLM agents know when to refuse to answer a question (due to ambiguity, missing evidence, false premises, etc.) instead of always producing a confident response. Frontier VLMs abstain far less reliably than humans (best model 42.79% recall vs. 91.17% human), and critically, when they fine-tune a 7B VLM to detect abstention-worthy questions, the apparent gains turn out to be driven almost entirely by textual/lexical shortcuts rather than actual grounding in the visual (or, by analogy, tool-return) evidence.

## Techniques to try

- Use an "ablate the grounding signal" control to sanity-check whether a flag/abstain classifier is really reading the evidence or just pattern-matching surface text: the paper compares a normal SFT model against variants with randomized visual input and with visual input removed entirely, plus pure text baselines (TF-IDF+LR, BERT) — "performance barely changes when visual inputs are randomized (7B-SFT-random) or removed entirely (7B-Text-SFT)... confirming that the signal comes almost entirely from linguistic patterns rather than multimodal reasoning" (Sec. 6.5). Directly applicable analogue for this project: run the malformed-tool-return flagging model against a control where the actual tool-return payload is scrambled/removed but surface phrasing (e.g., error keywords) is kept, to check whether "flag rather than assert" is grounded in the payload's actual schema/content violation or just triggered by superficial lexical cues.
- The paper's abstention taxonomy (five causes: actionability limitation, referential underspecification, preference dependence, information unavailability, false presupposition) is a useful checklist template for designing the ~300-example malformed-tool-return probe set — it argues for stratifying "should-flag" cases by *why* the input is bad rather than treating "malformed" as a single undifferentiated category, since different causes produced very different model behavior ("Information Unavailability... explicit cues to abstain" vs. "Referential Underspecification and Preference Dependence, which demand pragmatic disambiguation," Sec. 6.1).

## Baselines & datasets used

- AbstainEQA: 1,636 human-annotated abstention cases paired with 1,636 answerable cases from OpenEQA, expanded to 16,360 QA pairs via LLM paraphrasing; built on HM3D/ScanNet egocentric video.
- Models evaluated: Claude-Sonnet-4.5, GPT-5, GPT-4o, Gemini-2.5-Pro, Qwen2.5-VL-7B, Qwen3-VL (2B/4B/8B/32B) — all VLMs, none in the 1–2B on-device class relevant to this project's target model.
- Text-only control baselines for the SFT overfitting analysis: TF-IDF + logistic regression, and a small BERT classifier (Table 6).

## Pitfalls / negative results

- SFT-induced "abstention" is largely illusory: "7B-SFT" reaches 83.27% recall / 89.08% precision, but "7B-SFT-random" (visual input randomized) gets nearly identical 83.27%/87.93%, and "7B-Text-SFT" (no visual input at all) gets 86.12%/86.83% — i.e., removing or corrupting the actual evidence barely changes the flagging metrics (Table 6, Sec. 6.5). This is a direct warning against trusting a flag-rate/false-flag-rate pair as proof of genuine grounding; the same evaluation design (swap in a text-only or corrupted-evidence baseline) should be run against this project's malformed-tool-return probe before trusting its 0.80/0.10 numbers.
- Prompting to raise abstention recall trades away precision almost linearly and does not represent genuine improvement: on A-EQA, "recall increases sharply from 27.2% to 81.5% (coarse) and 99.5% (fine), whereas precision and accuracy fall to nearly half of their original values... this gain primarily reflects a trade-off between excessive caution and genuine uncertainty recognition" (Sec. 6.3, Table 4). Suggests the pre-registered flag-rate ≥0.80 / false-flag-rate ≤0.10 pairing is a real and non-trivial bar — naive prompting-only approaches would likely blow through one number to hit the other rather than satisfying both.
- Scaling and reasoning ("thinking" mode) do not reliably help: "adding reasoning chains does not improve abstention reliability... larger models (8B–32B) show consistent declines across both metrics" (Sec. 6.4, Table 5) — e.g. Qwen3-VL 8B-Instruct recall 33.92% drops to 27.02% with Thinking enabled. Scaling within a model family helped somewhat but "does not generalize across architectures" (Sec. 6.2).
- Even the best model is far below human ceiling on this abstention-style task (42.79% vs. 91.17% recall), a reminder that "know when you don't know" is a hard capability to instill even with large frontier models, let alone a 1.2B on-device model.

## Metric / eval choices

- Abstention judged via LLM-as-judge (GPT-4o) with recall/precision/accuracy/F1, validated against 300 human-labeled samples at Pearson r=0.88 (response scoring) and comparable Spearman correlation for abstention labels — a template for structuring a flag/false-flag evaluation prompt and validating an LLM judge against a human-labeled subset before trusting it at scale.
- Explicitly separates "response accuracy" from "abstention recognition" as two axes rather than one blended score — mirrors this project's schema-validity vs. flag-rate/false-flag-rate split.

## Open questions for our project

- The paper's domain (egocentric video QA, physical navigation) is far from this project's structured tool-calling/JSON setting, so none of its numbers transfer directly — but does the "textual-shortcut" failure mode it identifies (SFT rewarding surface lexical correlation over grounded judgment) apply just as much when the "evidence" is a JSON tool-return payload instead of an image? This seems highly likely and worth testing early with the same ablation trick (corrupt/replace the payload, see if flag behavior changes) before relying on SFT or DPO to instill "flag rather than assert."
- No content in this paper reads as an instruction addressed to the reader; it is a straightforward research paper and was treated only as descriptive source material.
