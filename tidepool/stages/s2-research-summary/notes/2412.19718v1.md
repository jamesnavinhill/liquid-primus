# 2412.19718v1 — Text2Insight: Transform Natural Language Text into Insights Seamlessly Using Multi Model Architecture

**Relevance:** skip
This is a master's thesis on an NL-to-SQL/visualization/QA pipeline (Llama3 + BERT + NER on an IPL cricket dataset) with no engagement with tool-calling reliability, JSON schema validity, quantization, or on-device deployment — the axes this project actually needs.

## TL;DR

The paper builds "Text2Insight," a multi-model system that turns a natural-language analysis request into a SQL query (via a pre-trained Llama3 model refined with an NER model), auto-selects a chart type, executes the query, and generates natural-language insights, plus separate BERT-based question-answering and predictive models — all demonstrated on an IPL cricket-match dataset. It is not about structured tool-calling for an agent gateway, model compression, or instruction-following robustness, so it does not bear on this project's post-training or quantization decisions.

## Baselines & datasets used

- Custom IPL (Indian Premier League cricket) match dataset used for SQL generation, EDA, time-series, and predictive-analysis evaluation ("the study provides a thorough exploration of the IPL dataset" — Section 4.4.2 area).
- Models used: pre-trained Llama3 for NL→SQL and insight generation, a NER model to refine SQL queries, a BERT model for question-answering and predictive/classification tasks, and T5-based models are cited for related visualization-command prediction work.

- Text2Insight is evaluated with accuracy, precision, recall, F1-score, a "syntactical evaluation," and BLEU score (reported as 99, 100, 99, 99, and 0.5 respectively) — a BI/NL-to-SQL evaluation battery, not comparable to BFCL, IFEval, or schema-validity metrics used in this project.
